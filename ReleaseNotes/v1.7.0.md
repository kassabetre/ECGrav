# ECGrav 1.7.0

Equilibriation and correlation time, audited and rebuilt.

The convergence test that every Monte Carlo driver in ECGrav depends on was comparing a squared
difference of window **means** against the variance of **individual** samples. Those two differ
by the effective sample size, so what the test actually measured was whether the autocorrelation
time was short — not whether the replicas had come to agree. A systematic 1σ offset between half
the replicas was declared converged **99% of the time**.

That is fixed, along with four other things found in the same audit. If you use
`RandomPureSimplicialComplexMCMC`, `GraphEquilibriate`, `GraphMultiHistogram` or
`GraphParallelTempering`, this release changes the numbers you get.

---

## ⚠️ Read before upgrading

**Minimum Wolfram Language version is now 15.0**, up from 14.2. The paclet will not install on
14.x.

**Seeded runs do not carry across 1.6.0.** Equilibriation now stops at a different sweep, so
`eqlT` — and everything downstream of it — differs for a given `SeedRandom`. Any `eqlT` recorded
from 1.6.0 or earlier is an **underestimate**: the old test was passing chains that had not
finished mixing.

**Two new messages appear on runs that used to be silent.** `::nosignal` fires when none of the
watched observables varied, so there was nothing to test. `::shortrun` fires when the
correlation-time run was short relative to what it measured. Both are the diagnostics working —
but `GraphEquilibriate::nosignal` in particular shows up routinely on high-beta replicas, which
freeze onto the ground state. Expect it in parallel tempering and multi-histogram runs.

**`::noconv` gained an argument slot** and now names the observable that agreed least well. If
you match on that message's text, update it.

**No public function was removed and no argument order changed.** One public setting is new.

---

## What changed

**The convergence threshold is calibrated.** It now compares `sqMeanPairwiseDiff` against
`expectedSqDiff` — twice the variance of a window mean, estimated from the scatter of
non-overlapping window means inside each track. Both sides average over the same number of
sweeps, so the comparison is exact at any autocorrelation and needs no correlation time (which
is not available until after equilibriation anyway). Measured on AR(1) tracks, the pass rate on
equilibriated chains is now flat in the autocorrelation at ~50% per check, where before it ran
from 100% down to 4%.

**Two observables are watched, not one** — the energy plus the vertex count, edge count or edge
density depending on the chain. A single scalar can be flat for reasons unrelated to mixing, and
one case was completely blind: the fixed-vertex chain at `labelingChoise -> 0` gives every state
weight 1, so the energy is identically 0 on every track. Ten facets on thirty vertices used to
report `converged -> True` at the first check, on every seed.

**A chain with nothing to measure now says so** rather than reporting success. This replaces a
metastability escape that read only each track's own drift, and so passed four tracks frozen at
four *different* energies however far apart they sat.

**The test runs once per window instead of once per sweep.** Consecutive checks shared all but
one of their points, so it was re-read hundreds of times over the same data and stopped at the
first favourable fluctuation.

**The correlation-time run no longer scales with the burn-in.** Equilibriation time and
measurement time are different quantities — how long the chain took to forget where it started,
against how long it takes to forget where it was a sweep ago — and only the second governs how
long you have to watch. The run is now `Min[5*eqlT, $ECGravMaxCorrelationSweeps]`.

**Parallel settings actually reach subkernels now.** `$ECGravMaxEquilibriationSweeps` was pushed
with `DistributeDefinitions`, which silently skips every symbol whose context has been registered
with `ParallelNeeds` — and the drivers' callers always register `ECGrav`. It shipped nothing
while reporting success, so raising the budget to fix a parallel run that would not converge had
**no effect**. Now pushed by assignment.

**Seven error messages** were written as single string literals spanning source lines, which put
newlines and tabs into the text so filled-in values rendered as misaligned columns. Rebuilt.

---

## New

- **`$ECGravMaxCorrelationSweeps`** (default `1000`) caps the correlation-time measurement run.
  Distributed to subkernels alongside `$ECGravMaxEquilibriationSweeps`. Raise it if you see
  `::shortrun`.

---

## Effect on results and runtime

On the one test system with a real transient (`Partition[Range[20], 2]`, `labelingChoise -> 2`),
the cross-track disagreement still outstanding when equilibriation exits drops from **1.24σ to
0.47σ**. The pass rate at a 1σ replica offset falls from 0.18 to 0.04.

That costs time, and honestly: equilibriation itself runs 1.0–1.6× longer, and `eqlT` grows more
than that because it carries a fixed window offset. End to end on
`RandomPureSimplicialComplexMCMC` at p=2, M=4, `labelingChoise -> 2`, five samples: **0.9 s →
6.7 s**. Most of that is the chain genuinely not having been mixed before. If it matters for your
workload, `$ECGravMaxCorrelationSweeps` is the knob.

## Testing

**172 tests, all passing** (`wolframscript -file Tests/ci-run.wls`, ~100 s).

The complex-space MCMC family went from one smoke test to full coverage this cycle — all four
definitions of `RandomPureSimplicialComplexMCMC` and both preparatory stages beneath it, pinned
values where the code is seed-reproducible and internal-consistency checks where it is not. Each
new test was verified against a deliberately mutated source.
[`Tests/README.md`](https://github.com/kassabetre/ECGrav/blob/main/Tests/README.md) documents the
reasoning, including the blind spots that remain.

## Install

Download `ECGrav-1.7.0.paclet` below, then:

```wl
PacletInstall["/path/to/ECGrav-1.7.0.paclet"]
```

Upgrading in a running session needs a `Quit[]` first — `Needs` is a no-op while `` ECGrav` `` is
already in `$Packages`, so the kernel keeps the old definitions.
